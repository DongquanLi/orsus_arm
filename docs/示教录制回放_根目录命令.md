# 示教录制与回放

在设备上执行：

```bash
cd ~/robot_y1
bash y1.sh record
```

自动慢速回零（夹爪保持）→ 确认静止 → 重力补偿 → 开始录制。开始前清空运动空间，Ctrl+C 停止前托住机械臂；退出时请求禁用电机。自动裁剪开头空白，约保留 3 秒，完整原件保存在 dataset/raw/。

停止录制后，在同一终端回放：

```bash
cd ~/robot_y1
bash y1.sh replay
```

新入口自动启动并管理 control 驱动，不需要第二个终端。默认 normal（本项目定义为轨迹时间轴 0.5×、SDK 速度 3）；起点到位后约等 3 秒。回放完成或中断时禁用并停止本次驱动。

指定文件或仅校验：

```bash
bash y1.sh replay records/demonstration_时间/dataset/episode_0.hdf5
bash y1.sh replay latest --dry-run
```

旧 replay_episode.py 是低层发布器，仍需独立 control 驱动。完整说明、档位、遥操作接口和相机边界见 [README](../README.md)。
